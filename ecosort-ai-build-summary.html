⚙️ Core Modules

classifier.py — WasteClassifier
  • 3-tier matching: Exact Alias Fuzzy ≥0.55
  • Returns confidence score + match method
  • Lifecycle engine: CO₂, landfill volume, tree equivalent
  • Fully cached via @st.cache_resource
  • Zero external dependencies — stdlib only
rag_engine.py — PolicyRAGEngine
  • 13 policy documents across 6 categories
  • TF-IDF keyword scorer: title ×2, tags ×3, content ×1
  • Category filter support, top-k configurable
  • Scores normalised 0–100% for display
  • No external API — deterministic, auditable
